This package extracts the owner's Education Mode for reuse. It does not create a new blanket licence for project code or supplied assets.

The browser bundle contains React/React DOM/Scheduler (MIT), Three.js 0.180.0 (MIT), Lucide React 0.468.0 (ISC, including Feather attribution), and Webpack runtime (MIT). Full notices are included in licenses/.

Nunito is distributed under the SIL Open Font License; Nunito-OFL.txt is included in licenses/ and dist/assets/.

The original education image URLs, replacements, sizes and hashes are preserved in dist/assets/sources.json. These include the existing Three.js Moon texture and the original Pexels Moon photograph. The Highlands/Poles thumbnails reuse the user-approved illustrative local Moon texture. No new image authorship or licence grant is asserted by this extraction.

The four JSON examples are saved calculations from the project's verified local science service, captured on 13 November 2026 for 1–8 October 2026 UTC. Their NASA/JPL/NAIF, LOLA and environmental source citations and limitations are retained with the returned evidence. These examples are not a live science service or a copy of the complete original raster/kernel datasets.

Procedural Moon artwork, teaching experiments, lesson UI and quiz logic are included as project code. Runtime operation of the bundled examples requires no original website or CDN.
